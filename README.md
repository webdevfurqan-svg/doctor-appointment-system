# Doctor Appointment System — Full-Stack Web Application

A full-stack web application for managing doctor appointments, patient scheduling, and medical portal interactions. Built with Node.js, Express, EJS, and MongoDB Atlas, and optimized for serverless cloud deployment on Vercel.

---

## 🚀 Live Demo & Repository

- **Live Application:** [https://doctor-appointment-system-two-ecru.vercel.app/](https://doctor-appointment-system-two-ecru.vercel.app/)
- **GitHub Repository:** [https://github.com/webdevfurqan-svg/doctor-appointment-system](https://github.com/webdevfurqan-svg/doctor-appointment-system)

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js, Session Authentication (`connect-mongo`)
- **Frontend:** EJS (Embedded JavaScript), HTML5, CSS3, JavaScript (ES6+)
- **Database:** MongoDB Atlas & Mongoose (Serverless connection pooling)
- **Deployment:** Vercel (@vercel/node serverless runtime)

---

## ✨ Key Features

- **Role-Based Workflows:** Patient and doctor interface flows for seamless booking and schedule management.
- **Persistent Sessions:** Serverless-compatible authentication powered by MongoDB session storage.
- **Dynamic EJS Rendering:** Clean, server-rendered views for appointment schedules and patient portals.
- **Serverless DB Connection Pooling:** Optimized Mongoose connection caching to prevent cold-start delays on Vercel.
